# shopping-list
Smart Shopping List is a beginner-friendly web development project created as part of a Data Structures case study. It helps users manage their shopping items easily through a simple and interactive interface.
Features

Add Items: Add new products to the shopping list.

Remove Items: Remove unwanted products.

Search Items: Quickly find specific products.

Display Items: View all items in the list.

Responsive Design: Use the application on desktop and mobile screens.

Technologies Used

HTML — Structure

CSS — Styling and responsive layout

JavaScript — Functionality and list management

How to Run

Download or clone this repository.

Open index.html in your web browser.

Enter an item and click Add Item.

Search for items or remove them whenever needed.

Learning Outcomes

Practiced JavaScript arrays and array operations.

Learned DOM manipulation and event handling.

Improved basic front-end web development skills.

Future Improvements

Add item quantities and prices.

Calculate the total shopping cost.

Save the shopping list using Local Storage.

Project Type: CSE Mini Project / Web Development

Note: This is a front-end web application. It does not require a server or database.
